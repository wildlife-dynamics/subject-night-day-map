User Guide

How to load subject-day-night-map, connect its data source and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select subject-day-night-map from the templates list.

2. Data sources

  • Access to an EarthRanger data source, set up as a connection

3. Settings

The run form asks for these. Fields with a default can be left as they are; fields marked Advanced are collapsed.

Set Workflow Details

FieldDescriptionDefault
Workflow Name (required)A name for this run.—
Workflow DescriptionOptional notes about this run.—

Set Time Range

FieldDescriptionDefault
Since (required)The start of the period to map.—
Until (required)The end of the period to map.—
TimezoneTimezone the times are given in.—

Connect to EarthRanger

FieldDescriptionDefault
Data source (required)Select one of your configured EarthRanger data sources. Choose it first: the Subject Group drop-down lists this data source's groups.—

Set Groupers

FieldDescriptionDefault
Group byOptional. Add a grouper to get one map per group: Category (only Subject Name, one map per subject), Temporal (e.g. one map per month) or Spatial (one map per spatial region). Leave empty for a single map of all subjects.—

Basemap URLs

FieldDescriptionDefault
Base mapsTile layers to draw under the tracks. The first layer in the list is the bottommost. Advanced.Esri World Topo Map, with Esri World Imagery at 50% opacity

Subject Group

FieldDescriptionDefault
Subject Group Name (required)The EarthRanger subject group to map, picked from a drop-down of the chosen data source's subject groups. ⚠️ A group with mixed subtypes could give unexpected results.—

Relocations To Trajectory

FieldDescriptionDefault
Trajectory Segment FilterLimits on segment length, duration and speed; segments outside them are dropped. Advanced.length 0.001 m – 100 km, time 1 s – 48 h, speed 0.01 – 500 km/h

4. Run it and find the results

The workflow writes its files to the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS), and shows its dashboard when it finishes.

OutputDescription
relocations.geoparquetThe cleaned location fixes, each with an is_night flag.
trajectories.geoparquetThe track segments built from those fixes.
One HTML map per groupThe day/night track map, as shown on the dashboard.
DashboardA Day Night Tracks map widget; with groupers set, the dashboard filter switches between groups.

On the map, day segments are amber (#e7a553) and night segments navy (#292965); night is when the sun is below the horizon at the fix's location and time.
