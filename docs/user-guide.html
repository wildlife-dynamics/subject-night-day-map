User Guide

How to load subject-day-night-map, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select subject-day-night-map from the templates list.

2. Data sources

  • Access to a EarthRanger data source, set up as a connection
