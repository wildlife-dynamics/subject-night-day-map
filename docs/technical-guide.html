Technical Guide

The steps subject-day-night-map runs, the packages they come from, its run-form overrides, and how to recompile and test it.

Run form

spec.yaml shapes the form in these ways:

  • rjsf-overrides turns Subject Group Name into a drop-down: the EarthRangerEnumResolver transform fills it with the subject groups of the data source picked under Connect to EarthRanger (depends_on: properties.er_connection.properties.data_source.properties.name).
  • rjsf-overrides $defs limits the Category grouper to Subject Name (ValueGrouper.properties.index_name.oneOf), the only subject column the maps are split on.
  • The steps are not in task groups, so each form override is keyed by its step id (e.g. subjectgroup_observations.properties.subject_group_name).
  • The Spatial grouper's Spatial Regions is still a text field. To make it a drop-down of the site's spatial feature groups, add an EarthRangerEnumResolver transform with type: spatial_feature_group on groupers.properties.groupers.
  • Open settings. Set Groupers, Basemap URLs and the Trajectory Segment Filter have no partial values, so they're on the form for each run. Without a ui:order, sections appear in the order of the steps.

Day/night classification

classify_is_night (ecoscope-platform) adds an is_night column to the relocations using ecoscope.analysis.astronomy.is_night: a fix is night when the sun is below the horizon at its coordinates and timestamp. IERS tables are not downloaded; the bundled data is accurate well beyond the minute-scale needed. Each track segment carries the flag of the fix it starts from, and Apply Color Map colours it #e7a553 (day) or #292965 (night).

Recompiling

spec.yaml is the source; ecoscope-workflows-subject-day-night-location-map-workflow/ is generated from it by wt-compiler.

./dev/recompile.sh --update   # keeps the lock file and bumps VERSION.yaml
./dev/recompile.sh --install  # a new lock file, and the packages installed

Testing

Each case in test-cases.yaml runs the workflow with its settings:

pixi run --manifest-path pixi.toml -e default bash dev/pytest-cli.sh subject_day_night_location_map --all
