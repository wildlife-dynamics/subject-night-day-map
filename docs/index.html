subject-day-night-map

Maps the movement tracks of every subject in an EarthRanger subject group, colouring each track segment by whether it was travelled by day (amber) or by night (navy). Night is worked out from the sun's position at each location fix, so it follows the real sunset and sunrise at that place and date.

What it does

StepWhat it does
Set Workflow DetailsName and description shown on the dashboard.
Set Time RangeThe period to map.
Connect to EarthRangerThe EarthRanger site to read from.
Set GroupersHow the maps are split: one map per subject, per time period or per spatial region. Leave empty for one map.
Basemap URLsTile layers drawn under the tracks.
Subject GroupFetches the location fixes of the subject group picked from the drop-down, for the time range.
Process RelocationsCleans the fixes and drops known bad coordinates (0,0 / 1,1 / 180,90).
Classify Is NightFlags each fix as night when the sun is below the horizon at its location and time.
Persist RelocationsSaves the classified fixes as relocations.geoparquet.
Relocations To TrajectoryJoins the fixes into track segments, dropping segments outside the Trajectory Segment Filter limits.
Persist TrajectoriesSaves the track segments as trajectories.geoparquet.
Map ColumnsRenames the subject and day/night columns (e.g. subject_name, is_night) and drops unused patrol columns.
Sort ValuesOrders day segments before night ones, so night segments are drawn on top.
Apply Color MapColours day segments amber (#e7a553) and night segments navy (#292965).
Split GroupsOne table of segments per group from Set Groupers.
Create Path LayerDraws each group's segments in their day/night colour, with a Day/Night legend and a tooltip.
Compute Fitted View StateZooms each map to its tracks.
Pair up geo_layers, view_state by groupPairs each group's path layer with its view.
Draw MapDraws each map over the base maps.
Persist Day Night MapSaves each map as an HTML file.
Create Map Widget Single ViewWraps each map as a Day Night Tracks widget.
Merge Widget ViewsCombines the per-group maps into one Day Night Tracks widget, so the dashboard filter switches between them.
Gather DashboardCollects the map widget into the dashboard.

What it produces

OutputDescription
relocations.geoparquetThe cleaned location fixes, each with an is_night flag.
trajectories.geoparquetThe track segments built from those fixes.
One HTML map per groupThe day/night track map, as shown on the dashboard.
DashboardA Day Night Tracks map widget; with groupers set, the dashboard filter switches between groups.
